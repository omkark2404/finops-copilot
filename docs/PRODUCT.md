# Product scope

Audience: engineers and FinOps analysts investigating uploaded billing exports.

Workflow: upload and validate → explore spend → inspect statistical flags → save an evidence run → record human review → simulate an explicitly assumed whole-dataset reduction.

The product supports investigation and hypothetical decisions. It does not execute cloud actions, prove root causes, certify FOCUS conformance, or demonstrate realized savings. Current scope, setup and limits are described in README, DATA, ML and LIMITATIONS. Sources and licensing are separate from maintenance branding.
